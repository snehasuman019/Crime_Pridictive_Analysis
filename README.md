# 🚔 Crime Predictive Analytics Dashboard
An interactive **Machine Learning Dashboard** built using **Python, Streamlit, and Scikit-learn** to analyze, visualize, and predict crime patterns using real-world crime data.
---
Live Link :-
https://crimepridictiveanalysis-qjelg5k5ghosk9rrtsaznm.streamlit.app/
---
## 📌 Project Overview
This project demonstrates the complete **Predictive Analytics workflow**, including:
- Data preprocessing & exploration
- Regression & classification models
- Clustering & pattern detection
- Dimensionality reduction (PCA)
- Model performance evaluation
- Interactive geospatial crime map
- Professional dark-themed dashboard UI

The dashboard allows users to interactively explore crime data, visualize hotspots, and analyze trends.
---
## 🎯 Objectives
- Analyze historical crime data
- Predict crime occurrence time and shift
- Identify crime hotspots using clustering
- Reduce dimensionality using PCA
- Evaluate models using cross-validation & ensemble methods
- Provide an interactive analytics dashboard
---
## 🧠 Machine Learning Techniques Used
### 🔹 Supervised Learning
- Linear Regression
- Logistic Regression
- Decision Tree Classifier
- Random Forest (Ensemble)
### 🔹 Unsupervised Learning
- K-Means Clustering
- Principal Component Analysis (PCA)
### 🔹 Model Evaluation
- Cross-validation (K-Fold)
- Accuracy, MAE, RMSE
- Feature Importance
