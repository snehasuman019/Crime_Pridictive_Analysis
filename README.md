
# 🚔 Crime Predictive Analysis using Machine Learning

## 📌 Overview

This project focuses on building an end-to-end machine learning pipeline to analyze crime datasets and predict crime attributes such as shift, location patterns, and hotspot zones using statistical and geospatial techniques.

---
Live Link :-
https://crimepridictiveanalysis-qjelg5k5ghosk9rrtsaznm.streamlit.app/
---
## 📊 Dataset

* Crime dataset containing **45,000+ records**
* Features include location, date/time, offense type, and categorical crime attributes.

---

## ⚙️ Features

* Data preprocessing (missing value handling, encoding, scaling)
* Exploratory Data Analysis (EDA)
* Geospatial hotspot detection using clustering
* Dimensionality reduction using PCA
* Model training & evaluation
* Interactive Streamlit dashboard deployment

---

## 🤖 Machine Learning Models Used

* Logistic Regression
* Random Forest
* K-Means Clustering
* Principal Component Analysis (PCA)

---

## 📈 Results

* Achieved **~80%+ prediction accuracy**
* Identified high-risk crime hotspot regions
* Reduced feature dimensionality using PCA for better visualization
* Compared multiple models using cross-validation metrics

---
